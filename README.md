# Dashboard-Rotacion-Empleados-4.
Dashboard interactivo de rotación de empleados IBM HR

Para organizar y facilitar la consulta del proyecto, se creó un repositorio público en GitHub denominado Dashboard-Rotacion-Empleados. Este repositorio contiene los archivos necesarios para el funcionamiento y la reproducción de la aplicación desarrollada.

La estructura incluye el archivo principal app.py, el conjunto de datos IBM HR Analytics Employee Attrition & Performance en formato CSV, el archivo requirements.txt con las dependencias necesarias y el documento README.md, que presenta la descripción del proyecto, los principales hallazgos, las instrucciones de instalación y ejecución local, y el enlace al dashboard publicado.
